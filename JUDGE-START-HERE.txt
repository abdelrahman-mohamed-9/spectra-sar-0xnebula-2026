SPECTRA 3.4 - OFFLINE JUDGE MISSION STUDIO
=========================================
1) Extract this ZIP fully (do not browse inside the ZIP).
2) Open judge-demo/index.html directly in Chrome/Edge/Safari.
   Windows: double click OPEN-JUDGE-DEMO-WINDOWS.cmd
   macOS:   double click OPEN-JUDGE-DEMO.command
3) No Python, NASA login, web service, internet, or access token needed.
4) Select a method, click a review region, use the inspection radius slider,
   and download the JSON/CSV evidence.
5) To run the full original SPECTRA processing workspace instead, use
   START.command (macOS) or START-WINDOWS.cmd (Windows).
