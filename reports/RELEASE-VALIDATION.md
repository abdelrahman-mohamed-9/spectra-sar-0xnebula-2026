## External comparison

| Method | Precision | Recall | F1 |
|---|---:|---:|---:|
| Fixed darkening | 60.9% | 56.7% | 58.7% |
| Robust darkening | 92.8% | 5.1% | 9.6% |
| Original logistic | 74.3% | 50.4% | 60.1% |
| Logistic with train-country F2 policy | 87.6% | 28.1% | 42.6% |
| Spatial gradient-boosting experiment | 79.2% | 26.6% | 39.8% |

The additional training-only policies did not improve the Spain result. F2 optimization on the training countries did not guarantee recall improvement on Spain. The original baseline remains visible and none of these models is transferred to NISAR. This release fixes missing implementation, integration and evidence handling; it does not claim a solved accuracy/generalization problem.

## Data that would close scientific gaps

1. A matched, independently checked NISAR pair with adequate source/radiometric/geometric evidence.
2. Independent event/change labels for the actual AOI, supplied under the reference contract, followed by expert review.
3. Spatial population counts and asset coverage suitable for the AOI and date. Optional population-raster processing and honest missing-source handling are implemented; suitable new measurements cannot be generated by software.
