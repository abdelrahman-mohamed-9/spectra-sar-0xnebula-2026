# تشغيل SPECTRA — فيز ١ + فيز ٢

1. فك ضغط الملف وافتح فولدر **SPECTRA-Phase2-Final**.
2. يفضل Python 3.12؛ ده الإصدار اللي اتجرب هنا.
3. افتح Terminal جوه الفولدر واكتب:

```bash
bash START.command
```

أول تشغيل هيحمّل المكتبات، فمحتاج إنترنت. بعد كده الصور والبيانات المطلوبة للتجربة موجودة بالفعل.

4. افتح `http://127.0.0.1:8765` لو الصفحة مفتحتش تلقائيًا.
5. انسخ **Access token** اللي ظهر في التيرمنال وحطه في الصفحة واضغط **Connect**.
6. اختار البيانات وطريقة الكشف واضغط **Run analysis**.
7. هتقدر تشوف قبل/بعد، التغيّرات المرشحة، النتائج، وتحمل الملفات. افتح `results/REPORT.md` لو عايز تقرأ النتيجة الجاهزة فورًا.

**Conservative** هو الوضع المحافظ الأصلي. **Broader review** بيطلع مرشحات أوسع للمراجعة، ومش معناه تلقائيًا إنه أدق. اختيار وضع العرض لوحده مش بيغيّر حساب التأثير؛ لازم تعمل Run جديد بالوضع المطلوب.

الملف فيه الكود الأصلي لفيز ١ وإصلاح فجوة السكان. مفيش داعي تجمع ZIPs قديمة أو تنقل ملفات يدويًا. الـPhase 2 API متوصل بنفس تطبيق M5 الأصلي.

للاختبارات:

```bash
bash START.command test
```

لو البورت مشغول:

```bash
bash START.command serve --port 8770
```

اقفل بـCtrl+C. حافظ على التوكن لنفسك. دليل التفاصيل: `README.md`.

**المتبقي العلمي:** labels مستقلة لألاسكا، تحقق مستقل من مقارنة الصورتين، وبيانات سكان مكانية صالحة. البرنامج بيعرض النواقص بوضوح؛ مش بيحوّل نقص البيانات لأرقام صفر أو ادعاء إن الضرر مؤكد.
